3. Données personnelles, Cookies & Polices locales

Ce site respecte le principe de minimisation absolue (Privacy-by-Design) :

  • Zéro traceur publicitaire : aucun script d'analyse comportementale (Google Analytics, Hotjar, Clarity) ni régie publicitaire.
  • Zéro cookie de suivi : aucun bandeau intrusif requis car aucun cookie tiers n'est déposé.
  • Polices auto-hébergées : l'ensemble des fichiers de polices .woff2 est servi directement depuis l'hébergeur sans requête externe vers Google Fonts, empêchant toute transmission d'adresse IP vers des serveurs tiers.
  • Applications Local-First : les démonstrations présentes dans le portfolio fonctionnent localement dans votre navigateur (LocalStorage / IndexedDB uniquement pour vos réglages locaux).
